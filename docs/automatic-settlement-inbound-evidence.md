# 自动结算的入库来源凭据

自动结算仍遵循库存快照的结算模式：验收入库、科室签收（领用／调拨）、科室消耗分别只处理对应模式。满足模式只是第一步；来源不明时保留库存动作及业务流水，跳过结算并记录流水 ID 供核对。

- **采购库存**：校验同机构、实际库存行上的采购明细来源，以及与之对应的真实验收入库流水。试剂、批号及单价须匹配；采购明细必须已有实际验收数量。仅有采购明细 ID、没有验收入库证据不计费。
- **非采购库存**：复用不可变的 `inventory_opening_balance`。要求证据在该业务动作发生时已存在，且机构、库存 ID、试剂、批号、库房、单价和数量均可核对；须有入库来源及凭证引用。发现后续同库同批入库或调入时不猜测混合库存的来源。
- **边界**：当前非采购证据只认可能够绑定到当前实际来源库存 ID 的凭据；不把期初凭据按批号继承到新的库存 ID。没有新增凭据审批页面、补账任务或历史回填。现有财务手工核对入口及其权限不变。

本修复复用现有正式表，不新增 Flyway 迁移。测试数据仅在隔离的测试库构造，不写正式库。
