# 审计统一收尾（2026-11-05）

范围：原 70 项确认代码问题与 15 项测试缺口；历史分批证据见 [进度台账](audit-remediation-progress-20261104.md)。

## 本轮实现

- 采购证照准入：手动采购、缺货转采购、智能补货、直接验收及采购单验收统一校验当前机构的启用供应商与证照。未维护证照、证照到期（含到期当天）、冻结或未生效均拒绝，不依赖定时任务是否及时运行。
- 显式续证审批：在证照详情先上传、核对新证明，再由主任或系统管理员在列表「续证审批」中选择附件、填写新证号/日期及说明。服务端校验权限、附件归属与存储可访问性，原行续期并写 RENEW 业务记录；相同有效信息重试不重复写记录。普通编辑不得解除失效状态。
- 供应商任何证照失效都会阻断采购。新增一张有效证照不会自动抵消其他冻结或过期证照；应逐张核对并使用续证审批，不猜测替代关系，不批量修改历史记录。
- 数量验收：CONSUMABLE/OTHER 可不填厂商批号和效期；系统按机构、到货日期发放 BATCH-CONS-YYYYMMDD-NNN。缺省效期保留 NULL，不伪造远期日期。已填写但过期的效期仍拒绝。虚拟批号号段用尽明确拒绝，不回绕。
- 无效期数量物料可参与 FEFO、普通调拨、申领拣选/签收及直接消耗；有标签效期的库存仍优先于无效期库存。试剂、校准品、质控品仍要求批号和标签效期。
- 删除并发收口：新采购引用和新批次创建与目录删除共用目录行锁；批准删除的引用检查改为加锁当前读，避免旧事务快照漏掉刚提交的采购。

## 待确认风险的保守处理

- 活跃附件：PDF 与常规位图保留预览，其余（包括 SVG、HTML）按二进制附件下载，加 nosniff 与 sandbox 响应头。未宣称已复现原审计的存储型 XSS，未改写历史文件。
- 历史均价：没有权威 unit_price 时先拒绝消耗，不自动用 avg_cost 填计费价格。权威价格补齐仍需业务核对，未修改历史金额。
