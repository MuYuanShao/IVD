# 主要审查问题修复（2026-10-10）

## 修复范围

- 自动审核：批次、效期、开瓶期限、设备校准、证照及库房状态由库存领域服务提供，客户端不能覆盖。设备按历史上机区间查批次；缺失或有歧义的上下文转人工。柔性试剂按 PRD 跳过设备校准规则。数值和布尔字段类型无效时转人工。
- 库存身份：验收、采购签收和库间调拨均使用试剂 ID＋批号＋仓库；新增相同粒度的唯一索引。
- 数量：采购验收、直接验收、拣货在服务层拒绝空值、零和负数；验收/拣货 DTO 同时校验。
- 拣货：源批次必须属于申领试剂，且在库、效期有效；申领行不能来自其他单据。
- 部分签收：锁定申领单，逐笔登记签收证据，只入库未签收流水；尚有未满足量时保留 PARTIAL_FULFILLED，允许继续补发。没有待签收流水时返回冲突。
- 结算、在途库存、追溯：统一使用逐笔签收证据，只有已签收流水可生成申领结算；已签收流水不再算在途；追溯使用实际签收时间。
- 日结：统一金额单位及试剂×仓库粒度；包含零库存；历史期末从当前金额扣除后续净变动；有上一日期末时使用该粒度的快照，否则使用已有历史流水。差异保留并按 PRD 1% 阈值判断。未定价证据阻止日结，重复日期拒绝重复生成。
- 分析：删除固定/随机 KPI 和前端演示回退；可计算的指标读取数据库，尚无权威来源的指标显示暂无数据；无审核数据的趋势为 null。按真实月份生成查询范围，结束日期包括整天。
