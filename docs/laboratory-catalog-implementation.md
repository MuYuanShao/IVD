# 检验项目与区间：已实现范围及接入

状态：本切片源码、测试和隔离预览实现；尚未部署到现有 `ivd` 业务数据库。五模块完整计划仍在实施中。

## 实现内容

- 检验项目：列表、详情、新增、编辑、启停用，项目编码在机构内唯一。
- 正常参考区间与设备测量范围：独立类型，定量/定性、方法学及原单位、性别、年龄（天）、生效日期/结束日期、启停用。
- 测量范围必须绑定本机构可访问的启用设备及定量项目；停用区间允许保留已停用设备的历史关联。设备读取复用库存模块 Service，未增加重复设备表。
- 项目和区间的详情、查询、写入均使用当前机构；外机构 ID 返回统一不存在响应。设备及项目使用复合归属外键，禁止跨机构引用。
- 区间保存先锁项目，再检查同机构现有配置，避免并发重叠写入。通用设备/不限性别配置与更具体配置也视为重叠。年龄和有效期为闭区间；相邻生效日期需从原结束日期的下一天开始。
- 更新必须携带当前 `version`。已有区间时，项目方法学、单位、结果类型不可直接修改，防止旧区间失配。项目名称可更新；这不是已签发报告快照功能。
- 判断输出 `NORMAL / LOW / HIGH / ABNORMAL / MISSING / UNIT_MISMATCH / CONFLICT / INVALID_RESULT`，未匹配或冲突不会判正常，不自动换算单位、生成诊断、复核或签发。
- JSON 中主键/引用 ID 及数值边界以字符串输出，避免前端 JavaScript 大整数和小数精度丢失。版本、年龄和分页仍为数字。

## API

| 方法 | URL | 内容 |
|---|---|---|
| GET / POST | `/api/v1/lab/items` | 分页 / 新增项目 |
| GET / PUT | `/api/v1/lab/items/{id}` | 详情 / 编辑项目 |
| GET / POST | `/api/v1/lab/intervals` | 分页 / 新增区间 |
| GET / PUT | `/api/v1/lab/intervals/{id}` | 详情 / 编辑区间 |
| POST | `/api/v1/lab/intervals/evaluate` | 风险提示，临床科室用户限定 |
| GET | `/api/v1/lab/devices/options` | 本机构可访问的启用设备，支持 keyword，最多50项 |

机构上下文由真实认证过滤器从数据库账号确认。基础维护只允许 `SYSTEM_ADMIN / LAB_DIRECTOR`；项目读取另允许 `LAB_DOCTOR / LAB_TECH`。普通管理员没有临床判断、复核或签发权。后台调用同样受 Service 权限校验。

- 项目与区间编辑分别使用独立 `LabTestItemEditorModal.vue`、`LabIntervalEditorModal.vue`；公共表格布局和分页加载使用通用组件/组合函数。前端枚举标签集中在 `laboratoryOptions.mjs`。
