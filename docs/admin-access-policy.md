# 固定 admin 全功能授权

用户明确指定 `admin` 为固定全功能管理员。实现只识别经过认证、用户名精确为 `admin` 且角色为 `SYSTEM_ADMIN` 的账号；其他管理员不继承例外，普通账号不能仅凭用户名获得权限。

- 后端角色注解允许该账号操作所有角色功能；临床服务允许其访问和签发。
- 前端该账号展示全部非隐藏业务菜单，临床模块启用后允许所有临床页面及全部导入资源。
- 保留机构隔离、临床科室归属、患者科室授权、请求校验、状态机、库存校验和不可变审计；本人不得复核或签发自己录入的报告。
- 功能授权不伪造部署就绪状态：临床开关关闭时页面提示不可用，不请求未注册接口。开启临床前必须配置独立加密密钥、真实科室归属及患者授权；不硬编码密钥、不猜测科室或绕过启动保护。CA 未接入仍不能模拟签名成功。

本轮修改仅构建验证，未替换正式服务、未修改正式账号科室、未开启临床功能、未提交推送。全部功能实际可用仍需完成上述部署前提。
